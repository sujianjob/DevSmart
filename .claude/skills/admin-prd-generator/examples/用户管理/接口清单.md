# 用户管理 - 接口清单

## 列表查询

**GET** `/api/system/user/list`

| 参数 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| username | String | 否 | 用户名，模糊匹配 |
| phone | String | 否 | 手机号，精确匹配 |
| status | Integer | 否 | 状态：0正常 1禁用 |
| beginTime | Date | 否 | 创建时间起 |
| endTime | Date | 否 | 创建时间止 |
| pageNum | Integer | 是 | 页码，从1开始 |
| pageSize | Integer | 是 | 每页条数 |

## 获取详情

**GET** `/api/system/user/{id}`

## 新增用户

**POST** `/api/system/user`

| 参数 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| username | String | 是 | 用户名，4-20字符 |
| password | String | 是 | 密码，6-20字符 |
| nickName | String | 是 | 姓名，2-20字符 |
| phone | String | 否 | 手机号 |
| email | String | 否 | 邮箱 |
| deptId | Long | 是 | 部门ID |
| roleIds | Long[] | 是 | 角色ID数组 |
| remark | String | 否 | 备注 |

## 编辑用户

**PUT** `/api/system/user`

参数同新增，但不包含 password 字段，增加 id 字段。

## 删除用户

**DELETE** `/api/system/user/{id}`

## 修改状态

**PUT** `/api/system/user/{id}/status`

| 参数 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| status | Integer | 是 | 状态：0正常 1禁用 |

## 重置密码

**PUT** `/api/system/user/{id}/resetPwd`

重置为默认密码，无需参数。
