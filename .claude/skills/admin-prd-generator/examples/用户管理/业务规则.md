# 用户管理 - 业务规则

## 校验规则

| 规则 | 详细说明 | 代码位置 |
|-----|---------|---------|
| 用户名唯一 | 新增时检查是否已存在相同用户名，编辑时排除自身 | UserService:45 |
| 密码强度 | 6-20字符，必须同时包含字母和数字 | UserService:52 |
| 手机号格式 | 11位数字，以1开头 | UserDTO:18 |
| 邮箱格式 | 符合标准邮箱格式 xxx@xxx.xxx | UserDTO:21 |

## 状态规则

| 规则 | 详细说明 | 代码位置 |
|-----|---------|---------|
| 禁用用户无法登录 | 登录时检查用户状态，禁用状态返回"账号已被禁用" | AuthService:30 |
| 超级管理员不能被禁用 | 禁用前检查是否为超级管理员角色 | UserService:72 |
| 超级管理员不能被删除 | 删除前检查是否为超级管理员角色 | UserService:78 |
| 不能删除自己 | 当前登录用户不能删除自己的账号 | UserService:80 |

## 系统行为

| 规则 | 详细说明 | 代码位置 |
|-----|---------|---------|
| 密码加密存储 | 使用 BCrypt 算法加密，不可逆 | UserService:55 |
| 新增自动填充 | 创建人、创建时间由系统自动填充 | UserService:60 |
| 编辑自动填充 | 更新人、更新时间由系统自动填充 | UserService:65 |
| 重置密码 | 重置为系统默认密码 123456 | UserService:90 |
| 软删除 | 删除操作仅标记删除状态，数据保留 | UserService:85 |
