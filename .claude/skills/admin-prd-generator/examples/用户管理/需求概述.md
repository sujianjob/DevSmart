# 用户管理 - 需求概述

## 功能简介

用户管理是系统的基础模块，用于管理后台系统的登录账号。支持用户的新增、编辑、删除、启用/禁用等操作。

## 业务场景

1. **管理员创建账号**：为新员工创建系统登录账号
2. **员工离职处理**：禁用离职员工账号，保留数据但禁止登录
3. **密码重置**：管理员可重置用户密码为默认值

## 页面清单

| 页面 | 路由 | 说明 |
|-----|------|------|
| 用户列表 | /system/user | 分页展示所有用户，支持搜索和批量操作 |
| 新增用户 | /system/user/add | 弹窗表单，填写用户基本信息 |
| 编辑用户 | /system/user/edit/:id | 弹窗表单，修改用户信息（不含密码） |

## 用户角色与权限

| 角色 | 可执行操作 |
|-----|-----------|
| 超级管理员 | 全部操作 |
| 普通管理员 | 新增、编辑、禁用（不能删除、不能操作超级管理员） |

## 状态定义

| 状态 | 说明 | 允许操作 |
|-----|------|---------|
| 正常 | 可正常登录系统 | 编辑、禁用、删除、重置密码 |
| 禁用 | 无法登录，数据保留 | 编辑、启用、删除 |

## 状态流转

```
[正常] ←──启用/禁用──→ [禁用]
```

- **禁用**：账号保留，但无法登录系统
- **启用**：恢复登录权限
- **删除**：软删除，数据保留但不可见
