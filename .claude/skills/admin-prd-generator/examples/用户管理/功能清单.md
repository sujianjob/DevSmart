# 用户管理 - 功能清单

## 1. 列表页

### 1.1 查询条件

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| 用户名 | 文本输入 | 否 | 支持模糊搜索，最多输入20字符 |
| 手机号 | 文本输入 | 否 | 精确匹配，11位数字 |
| 状态 | 下拉选择 | 否 | 可选：全部/正常/禁用 |
| 创建时间 | 日期范围 | 否 | 选择起止日期 |

### 1.2 列表字段

| 字段 | 宽度 | 排序 | 说明 |
|-----|------|-----|------|
| 用户名 | 120px | 支持 | - |
| 姓名 | 100px | - | - |
| 手机号 | 120px | - | 显示完整号码 |
| 邮箱 | 180px | - | - |
| 状态 | 80px | 支持 | 标签形式：正常(绿)/禁用(红) |
| 创建时间 | 160px | 支持 | 格式：YYYY-MM-DD HH:mm:ss，默认倒序 |
| 操作 | 200px | - | 编辑/删除/禁用/重置密码 |

### 1.3 操作按钮

| 按钮 | 权限标识 | 显示条件 | 二次确认 |
|-----|---------|---------|---------|
| 新增 | user:create | 始终显示 | 否 |
| 编辑 | user:update | 始终显示 | 否 |
| 删除 | user:delete | 非超级管理员 | 是，提示"确认删除该用户？" |
| 禁用 | user:update | 状态=正常 | 是，提示"禁用后该用户将无法登录" |
| 启用 | user:update | 状态=禁用 | 否 |
| 重置密码 | user:resetPwd | 始终显示 | 是，提示"确认重置密码为默认密码？" |

### 1.4 分页

- 默认每页显示 10 条
- 可选：10/20/50/100 条
- 显示总记录数

## 2. 新增/编辑表单

### 2.1 字段定义

| 字段 | 类型 | 必填 | 长度/格式 | 默认值 | 说明 |
|-----|------|-----|----------|-------|------|
| 用户名 | 文本 | 是 | 4-20字符，字母开头，只允许字母数字下划线 | - | 登录账号，创建后不可修改 |
| 密码 | 密码 | 是(新增) | 6-20字符，必须包含字母和数字 | - | 编辑时不显示此字段 |
| 确认密码 | 密码 | 是(新增) | 与密码一致 | - | 编辑时不显示此字段 |
| 姓名 | 文本 | 是 | 2-20字符 | - | 用户真实姓名 |
| 手机号 | 文本 | 否 | 11位数字，1开头 | - | - |
| 邮箱 | 文本 | 否 | 标准邮箱格式，最长50字符 | - | - |
| 部门 | 树形选择 | 是 | - | 当前用户部门 | 单选 |
| 角色 | 下拉多选 | 是 | - | - | 至少选择一个角色 |
| 备注 | 多行文本 | 否 | 最多200字符 | - | - |

### 2.2 表单校验

| 校验项 | 触发时机 | 错误提示 |
|-------|---------|---------|
| 用户名格式 | 失焦时 | 用户名必须以字母开头，只能包含字母、数字、下划线 |
| 用户名唯一 | 提交时 | 该用户名已存在 |
| 密码强度 | 失焦时 | 密码必须包含字母和数字 |
| 两次密码一致 | 失焦时 | 两次输入的密码不一致 |
| 手机号格式 | 失焦时 | 请输入正确的手机号 |
| 邮箱格式 | 失焦时 | 请输入正确的邮箱地址 |
