## 五、系统配置

### 5.1 参数配置

| 配置项 | 说明 | 默认值 |
|-------|------|-------|
| clue.duplicate.days | 线索去重天数 | 30 |
| clue.follow.remind.hours | 跟进提醒时间(小时) | 24 |
| clue.recycle.days | 线索回收天数 | 7 |
| export.max.rows | 导出最大行数 | 10000 |
| cache.dict.ttl | 字典缓存时间(分钟) | 5 |

### 5.2 缓存管理

| 功能 | 说明 |
|-----|------|
| 刷新字典缓存 | 强制刷新所有字典缓存 |
| 刷新渠道缓存 | 强制刷新渠道配置缓存 |
| 刷新产品缓存 | 强制刷新产品配置缓存 |
| 清空全部缓存 | 清空Redis所有缓存 |
