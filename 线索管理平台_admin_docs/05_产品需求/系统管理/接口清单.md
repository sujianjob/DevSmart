# 系统管理模块 - 接口清单

## 一、字典类型接口

### 1.1 字典类型分页查询

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/dictType/page` |
| 请求方式 | POST |
| 接口描述 | 分页查询字典类型列表 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| typeCode | String | 否 | 类型编码，模糊匹配 |
| typeName | String | 否 | 类型名称，模糊匹配 |
| status | String | 否 | 状态 |
| pageIndex | Integer | 否 | 页码，默认1 |
| pageSize | Integer | 否 | 每页条数，默认10 |

### 1.2 新增字典类型

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/dictType/add` |
| 请求方式 | POST |
| 接口描述 | 新增字典类型 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| typeCode | String | 是 | 类型编码，唯一 |
| typeName | String | 是 | 类型名称 |
| status | String | 否 | 状态，默认启用 |
| remark | String | 否 | 备注 |

### 1.3 修改字典类型

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/dictType/update` |
| 请求方式 | POST |
| 接口描述 | 修改字典类型 |

**请求参数**：同新增，额外必填 `id` 字段

### 1.4 删除字典类型

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/dictType/delete` |
| 请求方式 | POST |
| 接口描述 | 删除字典类型 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| id | Long | 是 | 字典类型ID |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| dictCode | String | 是 | 字典类型编码 |

### 2.2 根据字典编码获取字典项

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/dictItem/getByDictCode` |
| 请求方式 | GET |
| 接口描述 | 获取启用状态的字典项（供下拉选择使用） |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| dictCode | String | 是 | 字典类型编码 |

**响应数据**

```json
[
  {
    "itemValue": "值",
    "itemLabel": "标签"
  }
]
```
