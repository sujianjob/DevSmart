## 二、字典数据流转

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  新增类型   │────►│  保存数据库  │────►│  更新缓存   │
└─────────────┘     └─────────────┘     └──────┬──────┘
                                               │
                                               ▼
                                      ┌─────────────────┐
                                      │  Redis 缓存     │
                                      │  Key: dict:xxx  │
                                      │  TTL: 5min      │
                                      └─────────────────┘

┌─────────────┐     ┌─────────────┐
│  前端请求   │────►│  查询流程   │
└─────────────┘     └──────┬──────┘
                           │
              ┌────────────┴────────────┐
              │                         │
              ▼                         ▼
     ┌─────────────────┐       ┌─────────────────┐
     │  查询缓存       │       │  缓存未命中     │
     │  命中返回       │       │  查询数据库     │
     └─────────────────┘       └────────┬────────┘
                                        │
                                        ▼
                               ┌─────────────────┐
                               │  写入缓存       │
                               │  返回数据       │
                               └─────────────────┘
```

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐

                                               │
                    ┌──────────────────────────┴──────────────────────────┐
                    │                                                      │
                    ▼                                                      ▼

           │  编码不存在     │                                    │  编码已存在     │

                    │
                    ▼
           ┌─────────────────┐
           │  保存到数据库   │
           │                 │
           │  - 基本信息     │
           │  - 配置JSON     │

                    ▼
```

```
           └─────────────────┘
```

## 六、缓存刷新机制

```
┌─────────────┐
│  配置变更   │
│  触发点     │
└──────┬──────┘
       │
       ├─── 字典变更
       │         │
       │         ▼
       │    ┌─────────────────┐
       │    │ @CacheEvict     │
       │    │ dict:${code}    │
       │    └─────────────────┘
       │
       ├─── 渠道变更
       │         │
       │         ▼
       │    ┌─────────────────┐
       │    │ @CacheEvict     │
       │    │ channel:list    │
       │    └─────────────────┘
       │
       └─── 产品变更
                 │
                 ▼
            ┌─────────────────┐
            │ @CacheEvict     │
            │ product:${id}   │
            └─────────────────┘

手动刷新缓存：
       │
       ▼
┌─────────────────┐     ┌─────────────────┐
│  管理员操作     │────►│  调用刷新接口   │
│  "刷新缓存"     │     │  /cache/refresh │
└─────────────────┘     └────────┬────────┘
                                 │
                                 ▼
                        ┌─────────────────┐
                        │  RedisTemplate  │
                        │  delete(keys)   │
                        └─────────────────┘
```

## 八、系统配置热更新

```
┌─────────────────┐
│  修改系统配置   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  保存到数据库   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  发布配置变更   │
│  事件           │
└────────┬────────┘
         │
         ├─────────────────────────────────────────┐
         │                                         │
         ▼                                         ▼
┌─────────────────┐                       ┌─────────────────┐
│  刷新本地缓存   │                       │  广播到集群     │
│  (当前节点)     │                       │  (Redis Pub/Sub)│
└─────────────────┘                       └────────┬────────┘
                                                   │
                                                   ▼
                                          ┌─────────────────┐
                                          │  其他节点接收   │
                                          │  刷新本地缓存   │
                                          └─────────────────┘
```
