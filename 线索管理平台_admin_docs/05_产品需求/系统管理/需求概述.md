# 系统管理模块 - 需求概述

## 模块定位

系统管理模块负责平台基础配置和运营支撑功能，包括字典管理、渠道配置、产品管理、消息模板等。

## 功能架构

```
系统管理
├── 字典管理
│   ├── 字典类型管理
│   ├── 字典项管理
│   └── 字典缓存刷新
│
├── 渠道管理
│   ├── 渠道列表
│   ├── 渠道配置
│   └── 渠道状态管理
│
├── 产品管理
│   ├── 产品列表
│   ├── 产品PID配置
│   └── 产品状态管理
│
├── 消息模板
│   ├── 模板列表
│   ├── 模板变量配置
│   └── 模板预览
│
└── 系统配置
    ├── 参数配置
    ├── 缓存管理
    └── 日志查询
```

## 业务流程

### 字典管理流程

```
创建字典类型 → 添加字典项 → 启用字典 → 缓存生效
      ↓              ↓
   唯一性校验     值/标签必填
```

### 渠道配置流程

```
新增渠道 → 配置渠道参数 → 关联产品 → 启用渠道
              ↓
        渠道编码唯一
```

## 数据模型概览

### 字典类型 (DictTypeDO)

| 字段 | 说明 | 约束 |
|-----|------|------|
| id | 主键ID | 自增 |
| typeCode | 类型编码 | 唯一 |
| typeName | 类型名称 | 必填 |
| status | 状态 | true/false |
| remark | 备注 | - |

### 字典项 (DictItemDO)

| 字段 | 说明 | 约束 |
|-----|------|------|
| id | 主键ID | 自增 |
| dictCode | 所属字典编码 | 外键 |
| itemValue | 字典值 | 必填 |
| itemLabel | 字典标签 | 必填 |
| sort | 排序 | 数字 |
| status | 状态 | true/false |

### 渠道配置 (ChannelConfigDO)

| 字段 | 说明 | 约束 |
|-----|------|------|
| id | 主键ID | 自增 |
| channelCode | 渠道编码 | 唯一 |
| channelName | 渠道名称 | 必填 |
| channelType | 渠道类型 | 枚举 |
| status | 状态 | 0/1 |
| config | 配置JSON | - |

### 产品配置 (ProductConfigDO)

| 字段 | 说明 | 约束 |
|-----|------|------|
| id | 主键ID | 自增 |
| productId | 产品ID | 唯一 |
| productName | 产���名称 | 必填 |
| pid | 产品PID | - |
| status | 状态 | 0/1 |
