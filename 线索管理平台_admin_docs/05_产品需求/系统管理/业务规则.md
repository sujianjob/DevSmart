# 系统管理模块 - 业务规则

## 一、字典管理规则 (Dictionary Rules)

### DR-001: 字典类型编码唯一

| 项目 | 说明 |
|-----|------|
| 规则编号 | DR-001 |
| 适用场景 | 新增/修改字典类型 |
| 规则描述 | 字典类型编码在系统内必须唯一 |
| 异常信息 | "字典类型编码已存在" |

### DR-002: 字典类型编码格式

| 项目 | 说明 |
|-----|------|
| 规则编号 | DR-002 |
| 适用场景 | 新增字典类型 |
| 规则描述 | 编码只能包含大写字母、数字和下划线 |
| 正则表达式 | `^[A-Z][A-Z0-9_]*$` |
| 异常信息 | "编码格式不正确" |

### DR-003: 字典项值唯一

| 项目 | 说明 |
|-----|------|
| 规则编号 | DR-003 |
| 适用场景 | 新增/修改字典项 |
| 规则描述 | 同一字典类型下字典项值不能重复 |
| 异常信息 | "字典项值已存在" |

### DR-004: 字典项必填校验

| 项目 | 说明 |
|-----|------|
| 规则编号 | DR-004 |
| 适用场景 | 新增/修改字典项 |
| 规则描述 | 字典值和字典标签不能为空 |
| 异常信息 | "字典值不能为空" / "字典标签不能为空" |

### DR-005: 字典删除校验

| 项目 | 说明 |
|-----|------|
| 规则编号 | DR-005 |
| 适用场景 | 删除字典类型 |
| 规则描述 | 字典类型下有字典项时不能删除 |
| 异常信息 | "该字典类型下存在字典项，无法删除" |

## 五、缓存规则 (Cache Rules)

### CH-001: 字典缓存策略

| 项目 | 说明 |
|-----|------|
| 规则编号 | CH-001 |
| 规则描述 | 字典数据使用Redis缓存 |
| 缓存Key | `dict:${dictCode}` |
| 过期时间 | 5分钟（可配置） |
| 更新策略 | 修改后自动刷新缓存 |

```java
@Cacheable(value = "dict", key = "#dictCode")
public List<DictItem> getByDictCode(String dictCode) {
    return dictItemMapper.selectByDictCode(dictCode);
}
```

### CH-002: 渠道缓存策略

| 项目 | 说明 |
|-----|------|
| 规则编号 | CH-002 |
| 规则描述 | 渠道配置使用Redis缓存 |
| 缓存Key | `channel:list` |
| 过期时间 | 3分钟 |

### CH-003: 产品缓存策略

| 项目 | 说明 |
|-----|------|
| 规则编号 | CH-003 |
| 规则描述 | 产品配置使用Redis缓存 |
| 缓存Key | `product:${productId}` |
| 过期时间 | 5分钟 |

### CH-004: 缓存刷新触发

| 项目 | 说明 |
|-----|------|
| 规则编号 | CH-004 |
| 规则描述 | 配置变更后自动刷新对应缓存 |
| 触发场景 | 新增、修改、删除、状态变更 |

```java
@CacheEvict(value = "dict", key = "#dictCode")
public void updateDictItem(DictItem item) {
    dictItemMapper.update(item);
}
```
