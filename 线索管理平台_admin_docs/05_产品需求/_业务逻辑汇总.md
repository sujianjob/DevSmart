### 2. 字典数据全局引用

| 字典编码 | 引用模块 | 用途 |
|---------|---------|------|
| COMPANY_LIST | 人员管理 | 外部用户所属公司 |
| CLUE_CHANNEL_SOURCE_LIST | 线索管理、人员管理 | 渠道来源下拉 |
| BUSINESS_TYPE | 人员管理、线索管理 | 业务类型筛选 |
| ARCHIVE_REASON | 线索管理 | 归档原因选择 |
| ORDER_STATUS | 线索管理 | 订单状态枚举 |

### 3. 状态枚举统一定义

| 枚举类 | 值域 | 适用场景 |
|-------|------|---------|
| EnableEnum | 0=禁用, 1=启用 | 人员状态、渠道状态、产品状态 |
| ClueStatusEnum | 0-5 | 线索状态流转 |
| OrderStatusEnum | 0-3 | 订单状态流转 |
| DictItemStatusEnum | true/false | 字典项状态 |

## 三、安全规则汇总

### 1. 认证规则

| 规则 | 说明 | 实现 |
|-----|------|------|
| 密码加密 | MD5 + 盐值 + 2次迭代 | SimpleHash("md5", pwd, "123456", 2) |
| 账号禁用 | 禁用账号不能登录 | status="0" 检查 |
| 账号唯一 | 用户账号不能重复 | checkUserAccount() |

### 2. 数据权限

| 场景 | 规则 | 实现 |
|-----|------|------|
| 线索查看 | 普通用户只能看自己的线索 | followUserId 过滤 |
| 数据导出 | 需要特定权限 | 权限校验 |
| 手机号显示 | 中间4位脱敏 | 138****5678 |

### 3. 操作限制

| 操作 | 限制 | 说明 |
|-----|------|------|
| 导出数量 | 最大10000条 | 防止大量数据导出 |
| 线索转让 | 不能转给自己 | targetUserId != currentUserId |
| 删除字典 | 有字典项时不能删除 | 级联检查 |

## 五、数据一致性规则

### 1. 事务边界

| 操作 | 事务范围 | 说明 |
|-----|---------|------|
| 线索分发 | 单线索 | 每条线索独立事务 |
| 批量导入 | 批次 | 失败回滚整批 |
| 用户关联 | 先删后增 | 保证数据一致 |

### 2. 并发控制

| 场景 | 方案 |
|-----|------|
| 分发人员选择 | 轮询 + 上限检查 |
| 状态变更 | 乐观锁或状态前置校验 |
| 缓存更新 | 先更库后删缓存 |
