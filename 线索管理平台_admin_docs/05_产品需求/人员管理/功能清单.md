## 三、排班管理

### 3.1 功能说明

- 按月显示员工排班表格
- 固定列：用户姓名、账号
- 动态列：当月每一天（01、02、03...）
- 单元格点击可切换班次

### 3.2 操作功能

| 功能 | 说明 |
|-----|------|
| 月份选择 | 切换查看月份 |
| 单元格编辑 | 点击选择班次 |
| 排班导入 | Excel 批量导入 |

### 3.3 导入配置

| 配置项 | 值 |
|-------|---|
| 文件类型 | .xls, .xlsx |
| 上传接口 | /operate/workingSchedule/import |
| 模板下载 | /model/排班表导入模板.xlsx |
| 最大文件大小 | 10MB |
