## 四、跟进人获取流程

```
获取跟进人列表
       │
       ├─── 内部跟进人 (/vendorInnerUser/followerList)
       │         │
       │         ▼
       │    getDaoGouList(null) ──► 获取所有导购
       │
       └─── 外部跟进人 (/vendorUser/followerList)
                 │
                 ▼
            查询所有商户用户

转让人列表 (transferList)
       │
       ▼
  过滤条件: onlineState = "1" (启用状态)
       │
       ▼
  按业务类型过滤
```

## 六、加微号联动逻辑

```
选择加微主体 (wechatMainEntityId)
       │
       ▼
  调用 getLinkUser API
       │
       ├─── 返回主加微号列表 (primaryWechatAccountList)
       │
       └─── 返回次加微号列表 (secondaryWechatAccountList)
               │
               ▼
         选择主加微号
               │
               ▼
         次加微号列表过滤 (排除已选主加微号)
               │
               ▼
         选择次加微号 (支持多选)

切换加微主体时：
       │
       ▼
  清空主/次加微号选择
```
