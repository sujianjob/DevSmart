# 人员管理模块 - 需求概述

## 模块定位

人员管理模块负责管理系统中的所有用户账号，包括外部人员（BPO人员、商户操作员）和内部人员（公司员工、导购）。

## 功能架构

```
人员管理
├── 外部人员列表
│   ├── 用户账号管理（新增/编辑）
│   ├── 负责区域配置
│   ├── 负责渠道配置
│   └── 线索处理上限设置
│
├── 内部人员管理
│   ├── 账号关联（企微主体绑定）
│   ├── 主/次加微号配置
│   ├── 业务类型配置
│   └── 负责区域/渠道配置
│
└── 排班管理
    ├── 按月查看/编辑排班
    └── Excel 批量导入
```

## 用户角色

| 角色 | 说明 | 权限范围 |
|-----|------|---------|
| BPO | 外部操作人员 | 处理分配的线索 |
| BPO管理员 | 外部管理人员 | 管理BPO人员 |
| 内部员工 | 公司导购 | 线索跟进、订单处理 |

## 业务流程

### 外部人员创建流程

```
新增用户 → 设置账号密码 → 选择公司/角色 → 配置负责区域 → 启用账号
                ↓
         密码 MD5 加密存储
```

### 内部人员关联流程

```
选择内部用户 → 选择关联渠道 → 选择加微主体 → 配置主/次加微号 → 保存关联
                                    ↓
                           主/次加微号不能重复
```

## 数据模型概览

### 外部用户 (AuthVendorUserDO)

| 字段 | 说明 | 约束 |
|-----|------|------|
| userAccount | 用户账号 | 唯一 |
| userName | 用户姓名 | 必填 |
| password | 密码 | MD5加密 |
| role | 角色 | BPO/BPO_ADMIN |
| status | 状态 | 0禁用/1启用 |
| companyId | 所属公司 | 必填 |
| province/city | 负责区域 | 逗号分隔 |
| channels | 负责渠道 | 逗号分隔 |
| upperLimit | 线索处理上限 | 正整数 |

### 内部用户 (AuthInnerUserDO)

| 字段 | 说明 | 约束 |
|-----|------|------|
| userName | 用户账号 | 关联外部系统 |
| businessType | 业务类型 | 逗号分隔 |
| wechatMainEntityId | 企微主体ID | - |
| primaryWechatAccountId | 主加微号ID | - |
| secondaryWechatAccountId | 次加微号ID | 逗号分隔 |
| status | 状态 | 0禁用/1启用 |
