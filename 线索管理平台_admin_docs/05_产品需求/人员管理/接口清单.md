# 人员管理模块 - 接口清单

## 一、外部用户管理接口

### 1.1 新增外部用户

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/vendorUser/add` |
| 请求方式 | POST |
| 接口描述 | 新增外部用户（BPO人员） |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| role | String | 是 | 角色：BPO/BPO_ADMIN |
| companyId | String | 是 | 公司ID |
| userName | String | 是 | 用户姓名 |
| userAccount | String | 是 | 用户账号（唯一） |
| password | String | 是 | 密码 |
| status | String | 否 | 状态：0/1，默认1 |
| remark | String | 否 | 备注 |
| province | String | 否 | 负责省份，逗号分隔 |
| city | String | 否 | 负责城市，逗号分隔 |
| channels | String | 否 | 负责渠道，逗号分隔 |
| blankAddress | String | 否 | 是否接待空白地址：0/1 |
| upperLimit | Integer | 否 | 线索处理上限 |
| pids | String | 否 | 负责产品PID，逗号分隔 |

### 1.2 更新外部用户

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/vendorUser/update` |
| 请求方式 | POST |
| 接口描述 | 修改外部用户信息 |

**请求参数**：同新增，额外必填 `id` 字段

### 1.3 查询外部用户列表

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/vendorUser/list` |
| 请求方式 | POST |
| 接口描述 | 分页查询外部用户 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| userName | String | 否 | 用户姓名，模糊匹配 |
| userAccount | String | 否 | 用户账号，模糊匹配 |
| pageIndex | Integer | 否 | 页码，默认1 |
| pageSize | Integer | 否 | 每页条数，默认10 |

### 2.3 获取企微主体及加微号

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/vendorInnerUser/corpHostAccount` |
| 请求方式 | GET |
| 接口描述 | 获取企微主体列表及对应的加微号 |

**响应数据**

```json
{
  "corpList": [
    {
      "corpId": "企微主体ID",
      "corpName": "企微主体名称",
      "accountList": [
        {
          "accountId": "加微号ID",
          "accountName": "加微号名称"
        }
      ]
    }
  ]
}
```

## 三、排班管理接口

### 3.1 查询排班列表

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/workingSchedule/page` |
| 请求方式 | POST |
| 接口描述 | 按月份查询排班列表 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| month | String | 是 | 月份，格式：YYYY-MM |

### 3.2 更新排班

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/workingSchedule/update` |
| 请求方式 | POST |
| 接口描述 | 更新单个排班记录 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| id | Long | 是 | 排班记录ID |
| workShiftId | String | 是 | 班次ID |

### 3.3 导入排班

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/workingSchedule/import` |
| 请求方式 | POST (multipart/form-data) |
| 接口描述 | Excel 批量导入排班 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |

| file | File | 是 | Excel 文件 (.xls/.xlsx) |
