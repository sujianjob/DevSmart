# 线索管理模块 - 接口清单

## 一、我的线索接口

### 1.1 线索分页查询

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/clueData/page` |
| 请求方式 | POST |
| 接口描述 | 分页查询我的线索列表 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| clueName | String | 否 | 线索名称，模糊匹配 |
| mobile | String | 否 | 手机号 |
| clueStatus | String | 否 | 线索状态，多个逗号分隔 |
| channelSource | String | 否 | 渠道来源 |
| followUserId | String | 否 | 跟进人ID |
| createTimeStart | String | 否 | 创建时间起 |
| createTimeEnd | String | 否 | 创建时间止 |
| pageIndex | Integer | 否 | 页码，默认1 |
| pageSize | Integer | 否 | 每页条数，默认10 |

### 1.2 线索详情查询

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/clueData/detail` |
| 请求方式 | GET |
| 接口描述 | 获取线索详情信息 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| clueId | String | 是 | 线索ID |

### 1.3 添加跟进记录

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/clueFollow/add` |
| 请求方式 | POST |
| 接口描述 | 添加线索跟进记录 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| clueId | String | 是 | 线索ID |
| followResult | String | 是 | 跟进结果 |
| followContent | String | 是 | 跟进内容 |
| nextFollowTime | String | 否 | 下次跟进时间 |

### 1.4 查询跟进记录

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/clueFollow/list` |
| 请求方式 | POST |
| 接口描述 | 查询线索跟进记录列表 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| clueId | String | 是 | 线索ID |

### 1.5 线索转让

| 项目 | 说明 |
|-----|------|
| 接口路径 | `/operate/clueData/transfer` |
| 请求方式 | POST |
| 接口描述 | 将线索转让给其他人员 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
