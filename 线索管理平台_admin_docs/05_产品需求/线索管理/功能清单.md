# 线索管理模块 - 功能清单

## 一、我的线索

### 1.1 列表页功能

#### 搜索条件

| 字段 | 标签 | 类型 | 说明 |
|-----|------|------|------|
| clueName | 线索名称 | 输入框 | 模糊匹配 |
| mobile | 手机号 | 输入框 | 精确匹配 |
| clueStatus | 线索状态 | 下拉选择 | 多选 |
| channelSource | 渠道来源 | 下拉选择 | - |
| followUserId | 跟进人 | 下拉选择 | - |
| createTimeRange | 创建时间 | 日期范围 | - |
| followTimeRange | 跟进时间 | 日期范围 | - |

#### 列表字段

| 字段 | 标签 | 说明 |
|-----|------|------|
| clueId | 线索ID | 主键 |
| clueName | 线索名称 | - |
| mobile | 手机号 | 脱敏显示(中间4位*) |
| province | 省份 | - |
| city | 城市 | - |
| channelSourceName | 渠道来源 | - |
| clueStatusName | 线索状态 | 带颜色标签 |
| followUserName | 跟进人 | - |
| lastFollowTime | 最后跟进时间 | - |
| createTime | 创建时间 | - |

#### 操作按钮

| 按钮 | 位置 | 功能 | 权限 |
|-----|------|------|------|
| 查询 | 顶部 | 刷新列表 | - |
| 重置 | 顶部 | 清空筛选条件 | - |
| 导出 | 顶部 | Excel导出 | 需权限 |
| 查看详情 | 行内 | 打开详情弹窗 | - |
| 跟进 | 行内 | 打开跟进弹窗 | - |
| 转让 | 行内 | 打开转让弹窗 | 需权限 |

### 1.2 详情弹窗

| 区域 | 包含内容 |
|-----|---------|
| 基本信息 | 线索名称、手机号、省市、渠道来源等 |
| 跟进记录 | 时间轴形式展示历史跟进记录 |
| 关联订单 | 该线索关联的订单列表 |

### 1.3 跟进弹窗

| 字段 | 标签 | 类型 | 必填 |
|-----|------|------|------|
| followResult | 跟进结果 | 下拉选择 | 是 |
| followContent | 跟进内容 | 多行文本 | 是 |
| nextFollowTime | 下次跟进时间 | 日期选择 | 否 |

### 1.4 转让弹窗

| 字段 | 标签 | 类型 | 必填 |
|-----|------|------|------|
| targetUserId | 转让目标 | 下拉选择 | 是 |
| transferReason | 转让原因 | 多行文本 | 否 |

## 四、线索归档

### 4.1 归档列表

#### 搜索条件

| 字段 | 标签 | 类型 |
|-----|------|------|
| clueName | 线索名称 | 输入框 |
| archiveReason | 归档原因 | 下拉选择 |

| 字段 | 标签 | 说明 |
|-----|------|------|
| clueId | 线索ID | - |

#### 归档原因枚举

| 值 | 说明 |
|---|------|
| INVALID_PHONE | 无效号码 |
| NO_INTENTION | 无意向 |
| DUPLICATE | 重复线索 |
| COMPLETED | 已成交 |
| OTHER | 其他 |
