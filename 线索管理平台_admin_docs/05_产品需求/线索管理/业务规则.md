# 线索管理模块 - 业务规则

## 一、数据校验规则 (Validation Rules)

### VR-101: 线索名称必填

| 项目 | 说明 |
|-----|------|
| 规则编号 | VR-101 |
| 适用场景 | 线索导入/新增 |
| 规则描述 | 线索名称不能为空 |
| 异常信息 | "线索名称不能为空" |

### VR-102: 手机号格式校验

| 项目 | 说明 |
|-----|------|
| 规则编号 | VR-102 |
| 适用场景 | 线索导入/新增 |
| 规则描述 | 手机号必须为11位数字，以1开头 |
| 正则表达式 | `^1[3-9]\d{9}$` |
| 异常信息 | "手机号格式不正确" |

### VR-103: 线索去重校验

| 项目 | 说明 |
|-----|------|
| 规则编号 | VR-103 |
| 适用场景 | 线索导入 |
| 规则描述 | 同一手机号+渠道在指定天数内不能重复导入 |
| 配置项 | 去重天数可配置，默认30天 |
| 处理方式 | 跳过重复数据，记录日志 |

### VR-104: 跟进内容必填

| 项目 | 说明 |
|-----|------|
| 规则编号 | VR-104 |
| 适用场景 | 添加跟进记录 |
| 规则描述 | 跟进内容不能为空且长度不超过500字 |
| 异常信息 | "跟进内容不能为空" |

### VR-105: 转让目标校验

| 项目 | 说明 |
|-----|------|
| 规则编号 | VR-105 |
| 适用场景 | 线索转让 |
| 规则描述 | 转让目标必须是有效的启用状态用户，且不能转让给自己 |
| 异常信息 | "转让目标无效" / "不能转让给自己" |

## 二、分发规则 (Distribution Rules)

### DR-001: 地区匹配规则

| 项目 | 说明 |
|-----|------|
| 规则编号 | DR-001 |
| 规则描述 | 线索按省市匹配负责该地区的人员 |
| 匹配逻辑 | 优先精确匹配城市，其次匹配省份 |
| 空白地址处理 | 分发给配置了"接待空白地址"的人员 |

### DR-002: 渠道匹配规则

| 项目 | 说明 |
|-----|------|
| 规则编号 | DR-002 |
| 规则描述 | 线索按渠道来源匹配负责该渠道的人员 |
| 匹配逻辑 | 人员负责渠道包含线索渠道来源 |

### DR-003: 处理上限规则

| 项目 | 说明 |
|-----|------|
| 规则编号 | DR-003 |
| 规则描述 | 每人每日分发数量不超过设定上限 |
| 检查时机 | 分发前检查当日已分发数量 |
| 超限处理 | 跳过该人员，继续匹配其他人员 |

```java
// 伪代码示例
if (todayDistributedCount >= user.getUpperLimit()) {
    // 跳过该用户，选择下一个匹配的用户
    continue;
}
```

### DR-004: 轮询分发规则

| 项目 | 说明 |
|-----|------|
| 规则编号 | DR-004 |
| 规则描述 | 多人符合条件时，按轮询方式均匀分发 |
| 实现方式 | 记录上次分发人员，下次从下一个开始 |

## 三、状态流转规则 (Status Rules)

### SR-101: 线索状态流转

| 当前状态 | 可流转状态 | 触发动作 |
|---------|-----------|---------|
| 待分发 | 已分发 | 执行分发 |
| 已分发 | 跟进中 | 添加跟进记录 |
| 跟进中 | 已归档 | 归档操作 |
| 跟进中 | 弃用 | 弃用操作 |
| 跟进中 | 黑名单 | 加入黑名单 |

### SR-102: 订单状态流转

| 当前状态 | 可流转状态 | 触发动作 |
|---------|-----------|---------|
| 待确认 | 已确认 | 确认订单 |
| 已确认 | 已完成 | 完成订单 |
| 已确认 | 已取消 | 取消订单 |
| 待确认 | 已取消 | 取消订单 |

### SR-103: 状态变更记录

| 项目 | 说明 |
|-----|------|
| 规则编号 | SR-103 |
| 规则描述 | 所有状态变更自动记录操作日志 |
| 记录内容 | 操作人、操作时间、原状态、新状态、操作原因 |

## 四、数据安全规则 (Security Rules)

### SEC-001: 手机号脱敏

| 项目 | 说明 |
|-----|------|
| 规则编号 | SEC-001 |
| 适用场景 | 列表展示、导出 |
| 规则描述 | 手机号中间4位显示为**** |
| 示例 | 138****5678 |
| 配置 | 可按角色配置是否脱敏 |

```java
public static String maskMobile(String mobile) {
    if (StringUtils.isBlank(mobile) || mobile.length() != 11) {
        return mobile;
    }
    return mobile.substring(0, 3) + "****" + mobile.substring(7);
}
```

### SEC-002: 数据权限控制

| 项目 | 说明 |
|-----|------|
| 规则编号 | SEC-002 |
| 规则描述 | 普通用户只能查看自己负责的线索 |
| 管理员 | 可查看所有线索 |

### SEC-003: 导出权限控制

| 项目 | 说明 |
|-----|------|
| 规则编号 | SEC-003 |
| 规则描述 | 导出功能需要特定权限 |
| 导出限制 | 单次导出最大10000条 |

## 五、系统行为规则 (System Behavior)

### SB-101: 自动分发时机

| 项目 | 说明 |
|-----|------|
| 规则编号 | SB-101 |
| 规则描述 | 线索导入后自动触发分发 |
| 执行时机 | 导入完成后异步执行 |
| 失败处理 | 进入待分发池，等待手动分发 |

### SB-102: 跟进提醒

| 项目 | 说明 |
|-----|------|
| 规则编号 | SB-102 |
| 规则描述 | 超过设定时间未跟进的线索自动提醒 |
| 提醒方式 | 系统消息、企微通知 |
| 配置项 | 提醒时间间隔可配置 |

### SB-103: 线索回收

| 项目 | 说明 |
|-----|------|
| 规则编号 | SB-103 |
| 规则描述 | 长期未跟进的线索自动回收到公海 |
| 回收条件 | 超过配置天数未跟进 |
| 回收后状态 | 待分发 |
