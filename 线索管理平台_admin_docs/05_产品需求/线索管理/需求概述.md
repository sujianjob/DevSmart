# 线索管理模块 - 需求概述

## 模块定位

线索管理模块是系统的核心业务模块，负责线索的全生命周期管理，包括线索导入、分发、跟进、归档等环节。

## 功能架构

```
线索管理
├── 我的线索
│   ├── 线索列表（分页查询）
│   ├── 线索详情查看
│   ├── 线索跟进记录
│   ├── 线索状态变更
│   └── 线索转让
│
├── 订单线索
│   ├── 订单列表查询
│   ├── 订单状态管理
│   ├── 订单导出
│   └── 订单统计
│
├── 线索分发
│   ├── 待分发线索池
│   ├── 自动分发配置
│   ├── 手动分发操作
│   └── 分发规则管理
│
└── 线索归档
    ├── 归档线索查询
    ├── 归档原因分类
    └── 归档数据统计
```

## 业务流程

### 线索生命周期

```
线索导入 → 待分发 → 已分发(跟进中) → 归档/弃用/黑名单
    ↓           ↓           ↓
  数据校验    分发规则     状态流转
  去重处理    人员匹配     跟进记录
```

### 线索状态流转

```
┌─────────┐     ┌─────────┐     ┌─────────┐
│  待分发  │────►│  已分发  │────►│  已归档  │
└─────────┘     └────┬────┘     └─────────┘
                     │
                     ├────────►  弃用
                     │
                     └────────►  黑名单
```

## 数据模型概览

### 线索主表 (ClueDataDO)

| 字段 | 说明 | 约束 |
|-----|------|------|
| clueId | 线索ID | 主键 |
| clueName | 线索名称 | 必填 |
| mobile | 手机号 | 脱敏存储 |
| province/city | 省市 | - |
| channelSource | 渠道来源 | - |
| clueStatus | 线索状态 | 枚举 |
| followUserId | 跟进人ID | 关联用户 |
| followTime | 最后跟进时间 | - |
| createTime | 创建时间 | 自动 |

### 跟进记录 (ClueFollowRecordDO)

| 字段 | 说明 | 约束 |
|-----|------|------|
| id | 记录ID | ��键 |
| clueId | 线索ID | 外键 |
| followContent | 跟进内容 | - |
| followResult | 跟进结果 | 枚举 |
| followTime | 跟进时间 | - |
| operatorId | 操作人ID | - |

### 订单表 (ClueOrderDO)

| 字段 | 说明 | 约束 |
|-----|------|------|
| orderId | 订单ID | 主键 |
| clueId | 关联线索ID | 外键 |
| orderStatus | 订单状态 | 枚举 |
| amount | 订单金额 | - |
| productId | 产品ID | - |
