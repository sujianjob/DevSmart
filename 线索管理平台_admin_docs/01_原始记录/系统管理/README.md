# 系统管理模块

## 模块概述

系统管理模块提供系统级配置功能，包括参数配置和数据字典管理，为其他业务模块提供基础配置数据。

---

## 1. 参数配置

**URL**: `/#/systemConfiguration`

### 页面类型
列表页 + 新增/编辑弹窗

### 筛选条件

| 字段 | 类型 | 说明 |
|-----|------|------|
| 配置参数 | 文本输入 | 参数名称模糊搜索 |
| 备注 | 文本输入 | 备注信息搜索 |

### 列表操作

| 操作 | 说明 |
|-----|------|
| 查询 | 根据条件搜索 |
| 新增配置参数 | 添加新的配置项 |
| 编辑 | 编辑配置项 |

### 新增/编辑表单字段

| 字段名 | 控件类型 | 是否必填 | 说明 |
|-------|---------|---------|------|
| 配置参数 | 文本输入 | 是 | 参数键名 |
| 参数值 | 文本输入 | 是 | 参数值 |
| 启用状态 | 开关 | 否 | 是否启用 |
| 备注 | 文本输入 | 否 | 配置说明 |

## 2. 字典配置

**URL**: `/#/dictionaryManagement`

### 页面类型
列表页 + 新增/编辑弹窗 + 字典项配置子页面

### 筛选条件

| 字段 | 类型 | 说明 |
|-----|------|------|
| 字典名称 | 文本输入 | 名称模糊搜索 |
| 字典编码 | 文本输入 | 编码精确搜索 |

### 列表操作

| 操作 | 说明 |
|-----|------|
| 查询 | 根据条件搜索 |
| 重置 | 清空搜索条件 |
| 新增 | 添加新字典 |
| 编辑 | 编辑字典基本信息 |
| 配置字典 | 进入字典项配置页面 |

### 新增/编辑表单字段

| ���段名 | 控件类型 | 是否必填 | 说明 |
|-------|---------|---------|------|
| 字典名称 | 文本输入 | 是 | 字典显示名称 |
| 字典编码 | 文本输入 | 是 | 字典唯一标识 |
| 描述 | 文本输入 | 否 | 字典用途说明 |

## 3. 字典项配置（子页面）

**URL**: `/#/dictionaryManagement/dictionaryCodingList?id={字典ID}`

### 访问方式
从字典配置列表点击「配置字典」按钮进入

### 页面功能

| 功能 | 说明 |
|-----|------|
| 返回上一页 | 返回字典列表 |
| 编辑 | 编辑字典项 |
| 禁用 | 禁用字典项 |

### 截图
- 字典项列表: `screenshots/字典项配置.png`

## 参数配置 vs 字典配置

| 对比项 | 参数配置 | 字典配置 |
|-------|---------|---------|
| 用途 | 系统级键值对配置 | 下拉选项数据源 |
| 结构 | 扁平键值对 | 两级结构（字典-字典项） |
| 使用场景 | 开关配置、阈值设置等 | 状态选项、类型选项等 |
| 示例 | `max_retry=3` | 线索状态: 待跟进/跟进中/已完成 |

## 常见字典类型（推测）

基于系统中的下拉选项，推测以下字典配置：

| 字典名称 | 使用位置 |
|---------|---------|
| 角色类型 | 人员管理 |
| 业务类型 | 线索管理、人员管理 |
| 渠道类型 | 全系统 |
| 省份城市 | 地区选择 |
| 线索状态 | 线索管理 |
| 添加状态 | 线索管理 |
| 开口状态 | 线索管理 |
| 下单状态 | 线索管理 |
| 竣工情况 | 线索转化 |
| 未下单原因 | 线索管理 |
| 未竣工原因 | 线索转化 |
