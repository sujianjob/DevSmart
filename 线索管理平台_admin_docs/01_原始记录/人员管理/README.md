# 人员管理模块

## 模块概述

人员管理模块用于管理系统中的用户账号，分为外部人员和内部人员两类。

---

## 1. 外部人员列表

**URL**: `/#/userManagement/outUserLIst`

### 页面类型
列表页 + 新增/编辑弹窗

### 筛选条件

| 字段 | 类型 | 说明 |
|-----|------|------|
| 用户姓名 | 文本输入 | 模糊搜索 |
| 账号 | 文本输入 | 精确/模糊搜索 |

### 列表操作

| 操作 | 说明 |
|-----|------|
| 查询 | 根据筛选条件查询 |
| 新增用户 | 打开新增表单弹窗 |
| 编辑 | 编辑单条记录 |

### 新增/编辑表单字段

| 字段名 | 控件类型 | 是否必填 | 说明 |
|-------|---------|---------|------|
| 角色 | 下拉选择 | 是 | 选择用户角色 |
| 公司 | 下拉选择 | 是 | 选择所属公司 |
| 用户姓名 | 文本输入 | 是 | 用户真实姓名 |
| 用户账号 | 文本输入 | 是 | 登录账号 |
| 密码 | 密码输入 | 是（新增） | 设置登录密码 |
| 确认密码 | 密码输入 | 是（新增） | 确认密码 |
| 启用状态 | 开关 | 否 | 账号是否启用 |
| 备注 | 文本输入 | 否 | 备注信息 |
| 省份 | 级联选择 | 否 | 负责省份（可多选） |
| 城市 | 级联选择 | 否 | 负责城市（可多选） |
| 负责渠道 | 下拉选择 | 否 | 负责的渠道 |
| 是否主管 | 开关 | 否 | 是否为主管角色 |
| 负责产品PID | 文本输入 | 否 | 多个PID用逗号隔开 |

- 列表页: `screenshots/外部人员列表.png`
- 新增表单: `screenshots/外部人员_新增表单.png`

## 2. 内部人员管理

**URL**: `/#/userManagement/inUserLIst`

### 页面类型
列表页 + 编辑弹窗 + 排班管理子页面

### 筛选条件

| 字段 | 类型 | 说明 |
|-----|------|------|
| 用户姓名 | 文本输入 | 模糊搜索 |
| 账号 | 文本输入 | 精确/模糊搜索 |
| 角色 | 下拉选择 | 按角色筛选 |
| 业务 | 下拉选择 | 按业务类型筛选 |
| 渠道 | 下拉选择 | 按渠道筛选 |

### 列表操作

| 操作 | 说明 |
|-----|------|
| 查询 | 根据筛选条件查询 |
| 排班管理 | 进入排班管理子页面 |
| 编辑 | 编辑单条记录 |

### 编辑表单字段

| 字段名 | 控件类型 | 是否必填 | 说明 |
|-------|---------|---------|------|
| 角色 | 下拉选择 | 是 | 用户角色 |
| 加微主体 | 下拉选择 | 否 | 企业微信主体 |
| 主加微号 | 下拉选择 | 否 | 主要微信号 |
| 次加微号 | 下拉选择 | 否 | 备用微信号 |
| 关联业务 | 下拉选择 | 否 | 关联的业务类型 |
| 省份 | 级联选择 | 否 | 负责省份（可多选） |
| 城市 | 级联选择 | 否 | 负责城市（可多选） |
| 负责渠道 | 下拉选择 | 否 | 负责的渠道 |
| 日线索上限 | 数字输入 | 否 | 每日可接收线索上限 |
| 负责产品PID | 文本输入 | 否 | 多个PID用逗号隔开 |

### 截图
- 列表页: `screenshots/内部人员管理.png`
- 编辑表单: `screenshots/内部人员_编辑表单.png`

## 3. 排班管理（子页面）

### 访问方式
从「内部人员管理」页面点击「排班管理」按钮进入

### 页面功能

| 功能 | 说明 |
|-----|------|
| 选择月份 | 选择要管理的排班月份 |
| 排班导入 | 导入排班数据（Excel） |
| 返回上一页 | 返回内部人员管理 |

### 截图
- 排班管理页: `screenshots/排班管理.png`

## 外部人员 vs ���部人员区别

| 对比项 | 外部人员 | 内部人员 |
|-------|---------|---------|
| 定位 | 渠道/代理商人员 | 公司内部员工 |
| 账号管理 | 可新增账号 | 仅可编辑（账号由其他系统同步） |
| 密码设置 | 可设置 | 不可设置 |
| 排班功能 | 无 | 有 |
| 加微配置 | 无 | 有（主/次加微号） |
| 日线索上限 | 无 | 有 |
