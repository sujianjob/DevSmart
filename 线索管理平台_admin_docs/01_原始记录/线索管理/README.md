# 线索管理模块

## 模块概述

线索管理是系统的核心业务模块，负责线索的全生命周期管理，从线索获取、跟进到最终转化为订单。

---

## 1. 我的线索

**URL**: `/#/clueManagement/myClue`

### 页面类型
列表页 + 新增弹窗 + 查看详情弹窗 + 编辑弹窗

### 筛选条件

| 字段 | 类型 | 说明 |
|-----|------|------|
| 日期范围 | 日期选择 | 开始日期 - 结束日期 |
| 线索ID | 文本输入 | 精确搜索 |
| 手机号 | 文本输入 | 精确搜索 |
| 手机号后四位 | 文本输入 | 模糊搜索 |
| 线索渠道来源 | 下拉选择 | 渠道筛选 |
| 业务类型 | 下拉选择 | 业务分类 |
| 跟进人 | 下拉选择 | 按负责人筛选 |
| 添加状态 | 下拉选择 | 微信添加状态 |
| 开口状态 | 下拉选择 | 客户是否开口 |
| 下单状态 | 下拉选择 | 是否已下单 |
| 线索状态 | 下拉选择 | 线索当前状态 |
| 未下单原因 | 下拉选择 | 未转化原因 |
| 来源标识 | 下拉选择 | 来源标识 |
| 外部跟进人 | 下拉选择 | 外部人员 |
| 最新订单号 | 文本输入 | 订单号搜索 |
| 省份 | 下拉选择 | 省份筛选 |
| 城市 | 下拉选择 | 城市筛选 |

### 列表操作

| 操作 | 说明 | 位置 |
|-----|------|------|
| 查询 | 根据条件搜索 | 筛选区 |
| 新增线索 | 手动添加线索 | 工具栏 |
| 批量转移 | 批量转移给其他跟进人 | 工具栏 |
| 批量发送企微消息 | 批量发送企业微信消息 | 工具栏 |
| 导出 | 导出线索数据 | 工具栏 |

| 查看 | 查看线索详情 | 行操作 |
| 编辑 | 编辑线索信息 | 行操作 |
| 关键信息查询 | 查询敏感信息 | 行操作 |
| 线索转让 | 转让给其他人 | 行操作 |

## 线索状态流转

```
线索获取 → 待跟进 → 跟进中 → 已添加微信 → 已开口 → 已下单 → 已竣工
                              ↓           ↓        ↓
                           添加失败    未开口   未下单/退单
```

## 核心字段说明

### 线索状态相关

| 字段 | 说明 |
|-----|------|
| 添加状态 | 微信好友添加状态 |
| 开口状态 | 客户是否主动沟通 |
| 下单状态 | 是否已转化为订单 |
| 线索状态 | 线索整体状态 |

### 订单转化相关

| 字段 | 说明 |
|-----|------|
| 竣工情况 | 订单是否完成 |
| 未竣工原因 | 订单未完成的原因 |
| CRM订单号 | 对接CRM系统的订单号 |
| 报装号码 | 安装报装的联系电话 |
