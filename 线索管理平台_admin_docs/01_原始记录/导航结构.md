# 导航结构

## 完整菜单树

```
线索管理平台 (https://itest-clueadmin.jetmobo.com/)
│
├── 🏠 首页 (Welcome)
│   URL: /#/welcome
│
├── 👥 人员管理
│   ├── 外部人员列表
│   │   URL: /#/userManagement/outUserLIst
│   │   功能: 外部用户账号管理
│   │
│   └── 内部人员管理
│       URL: /#/userManagement/inUserLIst
│       功能: 内部员工账号管理
│       │
│       └── 排班管理 (子页面)
│           功能: 员工排班导入和管理
│
├── 📋 线索管理
│   ├── 我的线索
│   │   URL: /#/clueManagement/myClue
│   │   功能: 线索全生命周期管理
│   │
│   └── 线索转化
│       URL: /#/clueManagement/orderClue
│       功能: 线索转订单管理
│
└── ⚙️ 系统管理
    ├── 参数配置
    │   URL: /#/systemConfiguration
    │   功能: 系统参数键值对配置
    │
    └── 字典配置
        URL: /#/dictionaryManagement
        功能: 数据字典管理
        │
        └── 字典项配置 (子页面)
            URL: /#/dictionaryManagement/dictionaryCodingList?id={id}
            功能: 单个字典的选项配置
```

## URL 路由映射

| 菜单路径 | URL | 说明 |
|---------|-----|------|
| 首页 | `/#/welcome` | 登录后默认页面 |
| 人员管理 > 外部人员列表 | `/#/userManagement/outUserLIst` | 外部用户管理 |
| 人员管理 > 内部人员管理 | `/#/userManagement/inUserLIst` | 内部员工管理 |
| 人员管理 > 内部人员管理 > 排班管理 | 子页面 | 排班管理功能 |
| 线索管理 > 我的线索 | `/#/clueManagement/myClue` | 线索管理主页 |
| 线索管理 > 线索转化 | `/#/clueManagement/orderClue` | 转化订单管理 |
| 系统管理 > 参数配置 | `/#/systemConfiguration` | 系统参数配置 |
| 系统管理 > 字典配置 | `/#/dictionaryManagement` | 字典列表 |
| 系统管理 > 字典配置 > 字典项 | `/#/dictionaryManagement/dictionaryCodingList?id={id}` | 字典项配置 |

## 菜单层级说明

- **一级菜单**：3 个（人员管理、线索管理、系统管理）
- **二级菜单**：6 个
- **三级页面**：2 个（排班管理、字典项配置）

## 导航特点

1. **SPA 应用**：使用 Vue Router Hash 模式
2. **侧边栏导航**：左侧固定菜单栏
3. **面包屑**：部分页面支持面包屑导航
4. **子页面**：通过页面内按钮进入，非菜单入口
