# 数据模型 - 实体关系

## 核心实体

基于界面元素反向推导的数据模型。

---

## 1. 用户实体 (User)

### 外部用户 (ExternalUser)

```
ExternalUser {
  id: Long                    // 用户ID
  username: String            // 登录账号
  password: String            // 登录密码（加密存储）
  realName: String            // 真实姓名
  roleId: Long                // 角色ID
  companyId: Long             // 所属公司ID
  status: Boolean             // 启用状态
  remark: String              // 备注
  provinces: List<String>     // 负责省份（多选）
  cities: List<String>        // 负责城市（多选）
  channelId: Long             // 负责渠道ID
  isManager: Boolean          // 是否主管
  productPids: String         // 负责产品PID（逗号分隔）
  createTime: DateTime        // 创建时间
  updateTime: DateTime        // 更新时间
}
```

### 内部用户 (InternalUser)

```
InternalUser {
  id: Long                    // 用户ID
  username: String            // 登录账号（从其他系统同步）
  realName: String            // 真实姓名
  roleId: Long                // 角色ID
  wechatSubjectId: Long       // 加微主体ID
  primaryWechatId: Long       // 主加微号ID
  secondaryWechatId: Long     // 次加微号ID
  businessIds: List<Long>     // 关联业务ID
  provinces: List<String>     // 负责省份
  cities: List<String>        // 负责城市
  channelId: Long             // 负责渠道ID
  dailyClueLimit: Integer     // 日线索上限
  productPids: String         // 负责产品PID
  createTime: DateTime        // 创建时间
  updateTime: DateTime        // 更新时间
}
```

## 2. 线索实体 (Clue)

```
Clue {
  id: Long                    // 线索ID
  phone: String               // 手机号
  phoneLastFour: String       // 手机后四位（脱敏查询用）
  channelSourceId: Long       // 渠道来源ID
  businessTypeId: Long        // 业务类型ID
  followerId: Long            // 跟进人ID（内部用户）
  externalFollowerId: Long    // 外部跟进人ID
  addStatus: Integer          // 添加状态
  talkStatus: Integer         // 开口状态
  orderStatus: Integer        // 下单状态
  clueStatus: Integer         // 线索状态
  noOrderReason: String       // 未下单原因
  sourceTag: String           // 来源标识
  latestOrderNo: String       // 最新订单号
  province: String            // 省份
  city: String                // 城市
  wechatNickname: String      // 微信昵称
  remark: String              // 备注
  createTime: DateTime        // 创建时间
  updateTime: DateTime        // 更新时间
}
```

## 3. 订单实体 (Order)

```
Order {
  id: Long                    // 订单ID
  clueId: Long                // 关联线索ID
  orderNo: String             // 订单号
  crmOrderNo: String          // CRM订单号
  phone: String               // 客户手机号
  channelId: Long             // 下单渠道ID
  businessTypeId: Long        // 业务类型ID
  followerId: Long            // 跟进人ID
  completionStatus: Integer   // 竣工情况
  incompleteRemark: String    // 未竣工备注
  incompleteReason: String    // 未竣工原因
  sourceChannelId: Long       // 线索渠道来源
  sourceTag: String           // 来源标识
  installPhone: String        // 报装号码
  progressRemark: String      // 进度备注
  completionDate: Date        // 竣工日期
  orderDate: Date             // 下单日期
  province: String            // 省份
  city: String                // 城市
  wechatNickname: String      // 微信昵称
  createTime: DateTime        // 创建时间
  updateTime: DateTime        // 更新时间
}
```

## 5. 字典实体 (Dictionary)

```
Dictionary {
  id: Long                    // 字典ID
  name: String                // 字典名称
  code: String                // 字典编码
  description: String         // 描述
  createTime: DateTime        // 创建时间

  sort: Integer               // 排序
  status: Boolean             // 启用状态
  createTime: DateTime        // 创建时间
  updateTime: DateTime        // 更新时间
}
```

Schedule {

## 关系说明

1. **User → Clue**: 一个用户可以跟进多个线索 (1:N)
2. **Clue → Order**: 一个线索可以产生多个订单 (1:N)
3. **Dictionary → DictionaryItem**: 一个字典包含多个字典项 (1:N)
4. **InternalUser → Schedule**: 一个内部用户有多个月的排班记录 (1:N)
