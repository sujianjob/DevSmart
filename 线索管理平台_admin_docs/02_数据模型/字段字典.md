# 字段字典

## 概述

本文档汇总系统中所有业务字段的定义，便于开发和维护时参考。

---

## 用户相关字段

### 通用用户字段

| 字段名 | 中文名 | 数据类型 | 说明 |
|-------|-------|---------|------|
| id | 用户ID | Long | 主键 |
| username | 账号 | String | 登录账号，唯一 |
| realName | 用户姓名 | String | 真实姓名 |
| roleId | 角色 | Long | 关联角色表 |
| status | 启用状态 | Boolean | true=启用 |
| remark | 备注 | String | 备注信息 |
| provinces | 负责省份 | List | 可多选 |
| cities | 负责城市 | List | 可多选 |
| channelId | 负责渠道 | Long | 关联渠道字典 |
| productPids | 负责产品PID | String | 多个用英文逗号隔开 |

### 外部用户特有字段

| 字段名 | 中文名 | 数据类型 | 说明 |
|-------|-------|---------|------|
| password | 密码 | String | 登录密码 |
| companyId | 公司 | Long | 所属公司 |
| isManager | 是否主管 | Boolean | 主管角色标识 |

### 内部用户特有字段

| 字段名 | 中文名 | 数据类型 | 说明 |
|-------|-------|---------|------|
| wechatSubjectId | 加微主体 | Long | 企业微信主体 |
| primaryWechatId | 主加微号 | Long | 主要企微号 |
| secondaryWechatId | 次加微号 | Long | 备用企微号 |
| businessIds | 关联业务 | List | 关联的业务类型 |
| dailyClueLimit | 日线索上限 | Integer | 每日接收线索上限 |
