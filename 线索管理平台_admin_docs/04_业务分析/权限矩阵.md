## 角色权限设计（推测）

### 预设角色

| 角色 | 说明 | 权限范围 |
|-----|------|---------|
| 超级管理员 | 系统最高权限 | 所有功能 |
| 管理员 | 后台管理人员 | 人员管理 + 系统管理 |
| 运营主管 | 运营团队负责人 | 线索管理全量 + 查看所有人数据 |
| 运营专员 | 一线运营人员 | 我的线索（仅自己数据） |
| 外部合作方 | 渠道/代理商人员 | 有限的线索查看和操作 |

### 角色-权限映射（推测）

```
超级管理员
├── 人员管理：全部
├── 线索管理：全部
└── 系统管理：全部

管理员
├── 人员管理：全部
├── 线索管理：查看
└── 系统管理：全部

运营主管
├── 人员管理：查看
├── 线索管理：全部（含团队数据）
└── 系统管理：无

运营专员
├── 人员管理：无
├── 线索管理：查看+编辑（仅自己数据）
└── 系统管理：无

外部合作方
├── 人员管理：无
├── 线索管理：有限查看（仅自己数据）
└── 系统管理：无
```

## 数据权限设计（推测）

### 数据隔离级别

| 级别 | 说明 | 适用角色 |
|-----|------|---------|
| 全量数据 | 查看所有数据 | 超级管理员、管理员 |
| 团队数据 | 查看团队内所有人数据 | 运营主管 |
| 个人数据 | 仅查看自己的数据 | 运营专员、外部合作方 |

### 数据范围限制

| 维度 | 说明 |
|-----|------|
| 跟进人 | 按当前用户筛选 |
| 区域 | 按负责省份/城市筛选 |
| 渠道 | 按负责渠道筛选 |
| 业务 | 按关联业务筛选 |

---

## 敏感数据权限

### 敏感字段

| 字段 | 敏感级别 | 脱敏规则 |
|-----|---------|---------|
| 手机号 | 高 | 显示后四位，完整号需特殊权限 |
| 微信号 | 高 | 默认隐藏 |
| 地址 | 中 | 显示省市，详细地址需权限 |

### 敏感操作

| 操作 | 权限要求 |
|-----|---------|
| 关键信息查询 | `clue:sensitive` 权限 |
| 导出完整手机号 | 导出权限 + 敏感数据权限 |

## 菜单权限

### 菜单可见性

| 菜单 | 必要权限 |
|-----|---------|
| 人员管理 | 任一子菜单权限 |
| ├─ 外部人员列表 | `user:external:list` |
| └─ 内部人员管理 | `user:internal:list` |
| 线索管理 | 任一子菜单权限 |
| ├─ 我的线索 | `clue:list` |
| └─ 线索转化 | `order:list` |
| 系统管理 | 任一子菜单权限 |
| ├─ 参数配置 | `config:list` |
| └─ 字典配置 | `dict:list` |
