## 2. 人员管理流程

### 外部人员入职流程

```
1. 管理员创建账号
   └── 填写基本信息（姓名、账号、密码）
   └── 选择角色和公司
   └── 配置负责区域（省份/城市）
   └── 配置负责渠道和产品

2. 账号启用
   └── 设置启用状态为开启
   └── 外部人员可以登录系统

3. 日常调整
   └── 调整负责区域
   └── 变更角色权限
   └── 账号禁用/启用
```

### 内部人员配置流程

```
1. 账号同步（从其他系统）
   └── 账号自动创建

2. 管理员配置
   └── 配置加微主体和企微号
   └── 配置关联业务
   └── 设置日线索上限
   └── 配置负责区域和渠道

3. 排班管理
   └── 按月导入排班表
   └── 系统根据排班分配线索
```

### 手动分配/转让

```
线索转让流程：
1. 选择线索
2. 点击"线索转让"
3. 选择新的跟进人
4. 确认转让
5. 原跟进人失去该线索
6. 新跟进人接收线索
```

## 4. 订单转化流程

### 新增订单

```
1. 进入"线索转化"模块
2. 点击"新增订单"
3. 输入客户手机号查询
4. 关联已有线索
5. 填写订单信息
   └── 订单号
   └── CRM订单号
   └── 报装信息
6. 保存订单
7. 线索状态更新为"已下单"
```

## 5. 数据导入导出流程

### 数据导出

```
适用模块：我的线索、线索转化

流程：
1. 设置筛选条件
2. 点击"导出"按钮
3. 系统生成 Excel 文件
4. 下载到本地
```

### 数据导入

```
适用模块：订单导入、排班导入

流程：
1. 下载导入模板
2. 按模板格式填写数据
3. 点击"导入"按钮
4. 选择 Excel 文件
5. 系统校验数据
6. 显示导入结果
   └── 成功条数
   └── 失败条数及原因
```

## 6. 批量操作流程

### 批量转移

```
1. 勾选多条记录
2. 点击"批量转移"
3. 选择目标跟进人
4. 确认操作
5. 所有选中记录更新跟进人
```

### 批量发送企微消息

```
1. 勾选多条线索
2. 点击"批量发送企微消息"
3. 编辑消息内容（可选）
4. 确认发送
5. 系统通过企业微信 API 发送
6. 显示发送结果
```

## 关键业务指标（推测）

| 指标 | 说明 | 相关字段 |
|-----|------|---------|
| 添加率 | 添加成功数 / 总线索数 | addStatus |
| 开口率 | 开口数 / 添加成功数 | talkStatus |
| 转化率 | 下单数 / 开口数 | orderStatus |
| 竣工率 | 竣工数 / 下单数 | completionStatus |
