# 原型流程说明

> 迁移策略：无迁移，直接替换。

## 当前定位

现有 HTML / PNG 原型文件是历史视觉素材，部分页面仍保留旧的研发协作平台表达。新的 POC 不再沿用这些产品范围。

DevSmart 当前核心闭环是：

```text
输入需求 -> 澄清问题 -> 用户补充 -> PRD 生成 -> AC 生成 -> 待确认项 -> 评审输出
```

## 新 POC 页面

| 页面 | 说明 |
|:---|:---|
| 需求输入 | 输入一句或一段模糊需求 |
| 澄清问答 | 展示信息缺口和 3-5 个关键问题 |
| PRD 编辑 | 展示和编辑结构化 PRD |
| AC 清单 | 展示可测试验收标准 |
| 评审输出 | 汇总待确认项、风险、假设和修改记录 |

## 历史原型处理

- `PRD 生成与评审` 可作为新 PRD 编辑页的视觉参考。
- `新功能开发工作流` 可抽取需求输入和澄清问答的交互参考。
- 旧任务页面、旧智能体页面、旧日志页面仅作为历史素材，不进入当前 POC 范围。

## 不再包含

- 研发任务拆解。
- 研发执行材料。
- 智能体配置与调度。
- 外部项目管理工具同步。
- 代码、技术方案或接口相关工作。
