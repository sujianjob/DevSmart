# DevSmart 智能研发平台 - 原型与工作流演示

本文档按业务逻辑梳理了平台的核心功能与操作流程。

## 1. 全局态势感知
**场景**：技术总监或项目经理登录系统，查看研发效能的全景视图。

### 1.1 智能研发总览
核心仪表盘，展示项目健康度、资源投入、Agent 活跃度及关键指标。
![智能研发总览](智能研发总览.png)

### 1.2 总览细节
针对特定指标的深入分析视图。
![智能研发总览-细节](智能研发总览-细节.png)

---

## 2. 需求与项目管理流
**场景**：产品经理 (PM) 发起新项目，定义需求，并由系统辅助生成 PRD。

### 2.1 项目管理
项目的创建、列表维护及整体进度跟踪。
![项目管理](项目管理.png)

### 2.2 PRD 生成与评审
**核心流程**：输入需求简述 -> AI 生成详细 PRD -> 人工/AI 联合评审。
![PRD 生成与评审](PRD 生成与评审.png)

---

## 3. 任务分发与开发流
**场景**：需求确认后，系统或 Tech Lead 将需求拆解为任务，并调度 AI Agent 或人工进行开发。

### 3.1 任务管理与分发
展示任务看板，支持自动派发任务给合适的 Agent 或开发者。
![任务管理与分发](任务管理与分发.png)

### 3.2 新功能开发工作流
即 "Coding Agent" 的工作现场。展示代码生成、单元测试、CI/CD 流水线的执行过程。
![新功能开发工作流](新功能开发工作流.png)

---

## 4. 智能体 (Agent) 治理
**场景**：管理员对平台中的 AI 员工（Agents）进行管理、配置和性能监控。

### 4.1 智能体管理
Agent 的“花名册”，管理 Agent 的生命周期（上线、下线、升级）。
![智能体管理](智能体管理.png)

### 4.2 Agent 配置与监控
对单个 Agent 的详细参数配置（如模型参数、工具权限）及其运行时的资源监控。
![ Agent 配置与监控]( Agent 配置与监控.png)

---

## 5. 运维与审计
**场景**：保障系统稳定运行，追溯历史操作，沉淀团队知识。

### 5.1 团队管理
成员权限管理及组织架构维护。
![团队管理](团队管理.png)

### 5.2 历史工作流回放
**审计神器**：可回溯某个任务的完整执行链路，查看 Agent 的决策过程（Chain of Thought）。
![历史工作流回放](历史工作流回放.png)

### 5.3 知识库
沉淀项目文档、API 规范及最佳实践，供 Agent 检索学习。
![知识库](知识库.png)

### 5.4 警报与通知中心
汇集系统异常、任务超时等各类通知。
![警报与通知中心](警报与通知中心.png)

### 5.5 日志记录
系统级的底层运行日志查询。
![日志记录](日志记录.png)

### 5.6 系统设置
平台全局参数配置、安全策略设置及第三方服务集成管理。
![系统设置](系统设置.png)
