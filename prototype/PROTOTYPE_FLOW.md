# DevSmart 原型流程说明

本目录保留现有 HTML 和 PNG 原型资产。原型展示的是目标体验，不代表当前已经实现。

## 当前产品口径

DevSmart 是 AI 研发流程控制平面，核心闭环是：

```text
需求输入 -> PRD 生成/澄清 -> 人工审批 -> 任务拆解 -> 上下文包生成 -> 流程回放
```

## 原型页面

| 页面 | 说明 |
|:---|:---|
| 智能研发总览 | 展示项目和流程状态 |
| PRD 生成与评审 | 展示需求输入、PRD 生成和审批 |
| 任务管理与分发 | 展示任务拆解和分配 |
| 新功能开发工作流 | 展示任务上下文和执行状态 |
| 智能体管理 | 展示 Agent 配置和运行状态 |
| 知识库 | 展示文档和上下文资产 |
| 历史工作流回放 | 展示可审计流程轨迹 |
| 警报与通知中心 | 展示异常和提醒 |

## Coder Agent 说明

Coder Agent 不做 IDE 内编码体验。它负责：

- 生成任务上下文包。
- 调度人类开发者或外部 Coding Agent。
- 回收 PR、Commit 和执行摘要。
- 更新流程状态。

## 审计说明

流程回放展示：

- 状态变更。
- 工具调用。
- 输入输出摘要。
- 审批记录。
- 关键产物。

不展示模型内部推理过程。

## POC 对齐

30 天 POC 只实现核心页面：

- 任务创建页。
- PRD 审批页。
- 任务拆解页。
- 流程回放页。

其余原型页面作为后续方向保留。
