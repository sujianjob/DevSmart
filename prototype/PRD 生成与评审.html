PRD: 订单系统批量导出功能

schedule 生成于 2 分钟前 smart_toy 由 PM Agent (GPT-4o) 生成

info 1. 背景与目标

当前订单管理后台缺乏批量处理能力，导致运营团队在进行月度对账时需要手动逐条核对，效率极低。本功能旨在为运营人员提供高效的订单数据导出能力，支持 CSV 和 Excel 格式，以便进行线下分析和存档。

业务价值 预计每月节省运营工时 40+ 小时
优先级 P1 (High)

person 2. 用户故事 (User Stories)

US-101

作为运营管理员，我希望能够勾选多个订单并导出。

Value: 以便不必导出全量数据，只关注特定异常订单。
US-102
comment 1

作为系统用户，我希望导出过程在后台进行并在完成后收到通知。

Value: 以免长时间等待页面加载导致超时或无法进行其他操作。

fact_check 3. 验收标准 (AC)

  • check
    用户在订单列表页勾选至少 1 个订单后，“导出”按钮应从禁用状态变为可用状态。
  • check
    点击导出后，弹出模态框让用户选择格式 (CSV/Excel) 和包含的字段。
  • priority_high
    如果导出数据量超过 1000 条，系统应提示“任务已转入后台”，并关闭模态框。

    smart_toy Agent 注释: 需确认 1000 条的阈值是否与 S3 上传限制冲突。

  • check
    导出的文件必须包含 BOM 头，以防止在 Windows Excel 中打开乱码 (针对 CSV)。
