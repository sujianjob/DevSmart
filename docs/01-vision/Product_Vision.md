# 产品愿景

## 愿景

DevSmart 要成为研发团队的 AI 流程控制平面，让需求、任务、上下文、审批、执行结果和质量建议都可编排、可追踪、可复盘。

## 关键判断

- 研发效率瓶颈正在从“写代码”转向“明确需求、组织上下文、协调执行和复盘质量”。
- AI Coding Agent 会越来越强，DevSmart 不与 IDE 抢编码入口，而是做任务输入、过程控制和结果治理。
- 早期成功不取决于功能数量，而取决于 PRD 和任务上下文是否被真实团队采纳。

## 产品边界

| 不做 | 做 |
|:---|:---|
| IDE 内编码体验 | 研发流程编排 |
| 自动替代开发者 | 人机协作和审批 |
| 自动触发 CI/CD | CI 状态读取和质量建议 |
| 展示内部推理链 | 展示可审计流程轨迹 |

## 阶段目标

| 阶段 | 目标 |
|:---|:---|
| 30 天 | 跑通需求到任务上下文包的最小闭环 |
| 60-90 天 | 接入 GitHub 结构读取和任务系统单向创建 |
| 6 个月 | 建立流程协调、质量建议和内测案例 |
| 12 个月 | 建立企业治理、私有化部署和审计能力 |

详细产品定义以 [PRD](../../PRD.md) 为准。
