# 术语表

| 术语 | 说明 |
|:---|:---|
| DevSmart | AI 需求澄清与 PRD/AC 生成工作流工具 |
| RequirementPackage | 一次从模糊需求到评审输出的完整需求包 |
| Clarification | 澄清问题和用户回答 |
| PRD | 产品需求文档 |
| AC | Acceptance Criteria，验收标准 |
| GapItem | 信息缺口、假设、风险或待确认项 |
| ReviewRecord | 评审动作、意见和结论 |
| WorkflowEvent | 需求包状态变化和关键操作记录 |
| 模糊度判断 | 判断需求是否足够进入 PRD 生成 |
| 自动补漏 | 检查边界、异常、非目标和待确认项 |
| 评审输出 | PRD、AC、待确认项、风险摘要和修改记录的集合 |
