# 30 天 POC 详细目标

## 目标

30 天内交付可演示、可内测的最小闭环系统：

```text
需求输入 -> PRD 生成/澄清 -> 人工审批 -> 任务拆解 -> 上下文包生成 -> 流程回放
```

## 第 1 周：骨架与状态机

交付：

- FastAPI 后端骨架。
- React + Vite 前端骨架。
- LangGraph 状态机。
- Task / PRD / Event Schema。
- 基础 API。

验收：

- 能创建任务。
- 能看到状态变化。
- 能记录事件。

## 第 2 周：PRD 生成

交付：

- PM Agent。
- PRD Prompt。
- 澄清问题。
- PRD 审批和驳回。

验收：

- 清晰需求能生成 PRD。
- 模糊需求能生成澄清问题。
- 驳回后能重新生成。

## 第 3 周：任务与上下文包

交付：

- 任务拆解。
- `task_context.json`。
- 任务详情页。
- 上下文包预览。

验收：

- 一个 PRD 能拆 3-8 个任务。
- 每个任务有验收标准。
- 每个任务有上下文包。

## 第 4 周：指挥中心和演示

交付：

- 任务创建页。
- PRD 审批页。
- 任务拆解页。
- 流程回放页。
- 5 个演示样例。

验收：

- 能完整演示从需求到上下文包。
- 审批和驳回可用。
- 流程事件完整。

## 不包含

- Jira/Linear 双向同步。
- 自动提交代码。
- 自动触发 CI/CD。
- 企业级权限。
- 私有化部署。
- 内部推理过程展示。

## 指标

| 指标 | 目标 |
|:---|:---|
| PRD 生成成功率 | ≥ 80% |
| PRD 初稿可采纳率 | ≥ 50% |
| 任务拆解可采纳率 | ≥ 60% |
| 从需求到任务包耗时 | ≤ 10 分钟 |
| 内测用户愿意继续使用比例 | ≥ 60% |
