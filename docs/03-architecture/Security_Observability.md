# 安全与可观测性

## 安全底线

- Access Token 只存前端内存，不持久化到 localStorage。
- Refresh Token 使用 HttpOnly Cookie。
- 不记录明文密钥。
- 不记录不必要的个人敏感信息。
- AI 假设内容必须标记。
- 不做自动 CI/CD。

## 事件记录

每个关键动作都记录为 `WorkflowEvent`：

- 创建需求包。
- 生成模糊度判断。
- 生成澄清问题。
- 用户提交澄清答案。
- 生成 PRD。
- 生成 AC。
- 生成待确认项。
- 评审通过、驳回或要求修改。

## 可观测性

POC 阶段记录：

- 请求耗时。
- 模型路由别名。
- Token 用量。
- 需求包状态耗时。
- 生成失败摘要。

不记录模型内部推理过程。

## 后续扩展

- 需求质量评分趋势。
- 模板使用统计。
- 评审驳回原因分析。
- 团队级需求遗漏分布。
