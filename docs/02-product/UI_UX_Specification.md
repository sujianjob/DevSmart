# UI/UX 规格

## POC 页面

| 页面 | 核心动作 |
|:---|:---|
| 需求输入页 | 输入模糊需求、选择模板 |
| 澄清问答页 | 查看信息缺口、回答澄清问题 |
| PRD 编辑页 | 查看、编辑和重新生成 PRD |
| AC 页面 | 查看可测试验收标准 |
| 评审页 | 查看待确认项、风险摘要、评审记录 |

## 设计原则

- 工具型界面优先，避免营销化布局。
- 优先暴露“缺什么”和“下一步要确认什么”。
- AI 产物必须标记生成时间和可编辑状态。
- 推测内容必须标记为“AI 假设”。
- AC 必须以清单形式展示，方便逐条评审。

## 关键组件

- 需求输入框。
- 信息缺口面板。
- 澄清问题卡片。
- PRD 预览与编辑面板。
- AC 清单。
- 待确认项列表。
- 评审操作区。
