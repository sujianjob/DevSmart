# UI/UX 规格

## POC 页面

| 页面 | 核心动作 |
|:---|:---|
| 任务创建页 | 输入需求、提交任务 |
| PRD 审批页 | 查看 PRD、批准、驳回、补充意见 |
| 任务拆解页 | 查看任务列表、打开上下文包 |
| 流程回放页 | 查看状态、审批、产物和摘要 |

## 设计原则

- 工具型界面优先，避免营销化布局。
- 信息密度适中，优先让用户快速判断状态。
- 审批按钮必须清晰。
- AI 产物必须标记生成时间和可编辑状态。
- 推测内容必须标记为“AI 推测”。

## 关键组件

- 需求输入框。
- PRD 预览面板。
- 审批卡片。
- 任务表格。
- 上下文包 JSON 预览。
- 事件时间线。
