# 交互设计与用户界面规范 (UI/UX Specification)

## 1. 产品形态定义

### 1.1 核心交互载体

| 载体 | 定位 | 优先级 |
|:---|:---|:---|
| **Web Dashboard** | 主控制台，任务管理与监控 | P0 (核心) |
| **IDE 插件** | 轻量级通知与上下文查看 | P1 (重要) |
| **企微/钉钉机器人** | 消息推送与快捷审批 | P2 (增强) |
| **CLI 工具** | 开发者本地集成 | P2 (增强) |

### 1.2 Web Dashboard 信息架构

```
DevSmart Dashboard
├── 🏢 团队空间 (Team Space)           # 顶层导航 - 团队切换
│   ├── 团队选择器 (下拉/弹窗)
│   └── 全局搜索
├── 📁 项目工作区 (Project Workspace)  # 二级导航 - 项目切换
│   ├── 项目列表/切换
│   ├── 项目概览
│   └── 项目设置
├── 🏠 首页 (Home)                     # 当前项目首页
│   ├── 项目任务概览
│   ├── 待处理审批
│   └── 最近活动
├── 📋 任务中心 (Tasks)
│   ├── 看板视图 (Kanban)
│   ├── 列表视图 (List)
│   └── 任务详情页
├── 📝 需求工坊 (Requirements)
│   ├── PRD 生成器
│   ├── PRD 历史记录 (按项目归档)
│   └── 需求澄清对话
├── 📊 效能看板 (Analytics)
│   ├── 项目效能指标
│   ├── 团队效能指标
│   └── AI 使用统计
└── ⚙️ 设置 (Settings)
    ├── 团队管理 (成员、角色、权限)
    ├── 项目管理 (项目配置、归档)
    ├── 集成配置
    └── Agent 偏好
```

### 1.3 多租户层级结构

```
Organization (组织)
└── Team (团队)
    ├── Member (成员)
    │   └── Role (角色: Owner/Admin/Member/Guest)
    └── Project (项目)
        ├── Mission → PRD → Tasks
        ├── 知识库 (项目文档/代码上下文)
        └── 效能数据
```

**层级关系说明**：
- 一个组织可有多个团队
- 用户可属于多个团队
- PRD/任务必须归属于某个项目
- 效能数据可按项目/团队两个维度聚合

## 3. 交互状态设计

### 3.1 加载状态 (AI 处理中)

| 场景 | 预期耗时 | 交互方式 |
|:---|:---|:---|
| PRD 生成 | 30-60s | 流式输出 + 进度提示 + 思考过程可见 |
| 任务分发 | 5-10s | 骨架屏 + 状态动画 |
| 代码审查 | 10-30s | 进度条 + 阶段提示 |

**流式输出设计**：
- 逐字/逐行显示，模拟"思考过程"
- 显示当前处理阶段（"分析需求..."、"生成用例..."）
- 可随时中断

### 3.2 错误状态

| 错误类型 | 错误提示 | 恢复操作 |
|:---|:---|:---|
| AI 生成失败 | "生成遇到问题，请稍后重试" | [重试] [手动编写] |
| 网络超时 | "网络连接超时" | [重试] |
| 权限不足 | "您没有审批权限" | [请求权限] |
| 输入无效 | "请提供更详细的需求描述" | 高亮输入框 |

### 3.3 空状态

| 页面 | 空状态文案 | 引导操作 |
|:---|:---|:---|
| 任务列表 | "还没有任务，从需求开始吧" | [创建第一个 PRD] |
| PRD 历史 | "尚未生成过 PRD" | [开始生成] |
| 效能看板 | "数据采集中，预计 24h 后展示" | - |

## 4. 设计规范

### 4.1 配色方案 (Dark Mode First)

| 用途 | 色值 | 示例 |
|:---|:---|:---|
| 背景主色 | `#0D1117` | 页面背景 |
| 卡片背景 | `#161B22` | 内容卡片 |
| 主操作 | `#238636` | 主按钮 |
| 强调色 | `#58A6FF` | 链接、高亮 |
| 警告 | `#F85149` | 错误提示 |
| 文字主色 | `#C9D1D9` | 正文 |
| 文字次色 | `#8B949E` | 辅助文字 |

### 4.2 字体规范

| 用途 | 字体 | 字号 |
|:---|:---|:---|
| 标题 | Inter Bold | 24px / 20px / 16px |
| 正文 | Inter Regular | 14px |
| 代码 | JetBrains Mono | 13px |
| 辅助 | Inter Regular | 12px |

### 4.3 间距规范

- 基础单位：4px
- 卡片内边距：16px / 24px
- 元素间距：8px / 12px / 16px
