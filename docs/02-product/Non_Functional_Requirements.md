# 非功能需求

## POC 阶段要求

| 维度 | 要求 |
|:---|:---|
| 响应 | 创建任务接口 < 1 秒返回任务 ID |
| 流式反馈 | PRD 生成和状态变化通过事件流展示 |
| 可恢复 | LangGraph 状态支持中断后恢复 |
| 可审计 | 每个关键动作记录事件 |
| 安全 | 不在 localStorage 持久化 Access Token |
| CI/CD | 只读状态读取，不自动触发构建、测试、发布 |

## 生产阶段再评估

- 多租户隔离。
- SSO。
- 私有部署。
- 高可用。
- 灾备。
- 完整合规审计。

POC 阶段不提前建设企业级复杂度。
