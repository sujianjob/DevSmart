# 非功能需求

## POC 阶段要求

| 维度 | 要求 |
|:---|:---|
| 响应 | 创建需求记录 < 1 秒返回 |
| 生成反馈 | PRD/AC 生成过程展示阶段状态 |
| 可恢复 | 页面刷新后可找回当前需求包 |
| 可审计 | 每个关键动作记录事件 |
| 安全 | 不在 localStorage 持久化 Access Token |
| 可用性 | 用户可编辑所有 AI 生成内容 |

## 内容质量要求

- 所有假设必须显式标记。
- 所有待确认项必须可单独汇总。
- AC 必须可测试、可判断。
- PRD 必须包含非目标和边界场景。

## 生产阶段再评估

- 多空间隔离。
- SSO。
- 权限模板。
- 高可用。
- 完整合规审计。

POC 阶段不提前建设企业级复杂度。
