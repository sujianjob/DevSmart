# 用户画像

## 产品经理

- 目标：快速得到可评审 PRD。
- 痛点：需求边界遗漏、文档起草耗时、频繁被追问。
- 价值：PRD 初稿、澄清问题、验收标准。

## 技术负责人

- 目标：把需求拆成可执行任务。
- 痛点：任务拆解耗时、依赖不清、上下文分散。
- 价值：任务拆解、优先级、依赖和风险提示。

## 研发工程师

- 目标：拿到足够上下文后开始执行。
- 痛点：任务描述空泛、需求反复确认。
- 价值：上下文包、验收标准、测试建议。

## QA

- 目标：快速识别测试场景和风险。
- 痛点：用例整理重复、回归范围不清。
- 价值：测试场景、风险点、人工执行清单。

## 管理者

- 目标：看到流程效率和卡点。
- 痛点：状态分散、复盘困难。
- 价值：流程回放、审计事件和耗时指标。
