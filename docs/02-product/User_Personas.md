# 用户画像

## 产品经理

- 目标：快速得到可评审 PRD 和 AC。
- 痛点：需求边界遗漏、文档起草耗时、评审前反复补材料。
- 价值：澄清问题、PRD 初稿、AC、非目标和待确认项。

## 业务方

- 目标：把想法说清楚，让产品团队理解。
- 痛点：只能描述目标和现象，难以补齐流程、边界和成功标准。
- 价值：通过问题引导补充关键信息。

## 产品负责人

- 目标：判断需求是否可以进入评审或排期。
- 痛点：PRD 质量参差不齐，评审时才发现重大遗漏。
- 价值：需求质量评分、风险摘要和待确认项。

## 协作者

- 目标：基于清晰需求开展设计、测试、运营或交付准备。
- 痛点：需求背景不足、验收口径不一致。
- 价值：用户故事、流程、边界场景和 AC。
