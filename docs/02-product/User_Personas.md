# 用户画像 (User Personas)

## 1. 产品经理 (PM/PO)

### 基本信息
- **角色名称**：小林
- **职位**：高级产品经理
- **经验**：5 年产品经验

### 痛点
1. 撰写 PRD 耗时长，且常被研发反复追问细节
2. 难以覆盖所有边缘场景，上线后频繁补丁
3. 需求变更时，影响范围难以评估

### 目标
- 快速输出高质量、可执行的 PRD
- 减少与研发的无效沟通
- 让 AI 帮助发现遗漏的边缘场景

### 期望的 AI 行为
- **主动澄清**：发现模糊需求时主动追问
- **智能校验**：自动检查 PRD 逻辑一致性
- **变更分析**：需求变更时自动评估影响范围

## 2. 研发工程师 (Developer)

### 基本信息
- **角色名称**：小王
- **职位**：全栈工程师
- **经验**：3 年开发经验

### 痛点
1. 频繁被打断：查文档、配环境、参加会议
2. PRD 不清晰，需要反复确认需求
3. 技术债务累积，重构时间不足

### 目标
- 专注于核心业务逻辑开发
- 减少低价值事务的时间消耗
- 获得清晰、可执行的任务描述

### 期望的 AI 行为
- **上下文注入**：任务启动时自动提供相关代码、文档
- **进度同步**：自动更新任务状态，减少手动填写
- **技术建议**：在合适时机推送代码质量建议

## 3. 质量工程师 (QA)

### 基本信息
- **角色名称**：小张
- **职位**：测试工程师
- **经验**：4 年测试经验

### 痛点
1. 用例编写重复性高，效率低
2. 回归测试周期长，难以快速响应
3. Bug 定位困难，日志信息不完整

### 目标
- 自动生成测试用例框架
- 精准筛选回归范围
- 获得结构化的上下文信息辅助 Bug 分析

### 期望的 AI 行为
- **用例生成**：基于 PRD 自动生成测试场景
- **智能筛选**：根据代码变更推荐回归用例集
- **根因建议**：测试失败时提供可能的根因假设

## 4. 技术负责人 (Tech Lead)

### 基本信息
- **角色名称**：老李
- **职位**：技术总监
- **经验**：10 年研发管理经验

### 痛点
1. 团队效能难以量化评估
2. 知识沉淀不足，人员流动造成断层
3. 流程规范执行不一致

### 目标
- 实时掌握团队效能数据
- 建立组织级知识库
- 确保流程规范落地执行

### 期望的 AI 行为
- **效能看板**：自动采集并展示研发效能指标
- **知识沉淀**：自动归档决策过程和解决方案
- **规范检查**：在关键节点自动检查流程合规性
