# 功能规格

> 产品范围以 [PRD](../../PRD.md) 为准，本文只保留功能清单和优先级。

## P0：30 天 POC

| 功能 | 说明 | 验收 |
|:---|:---|:---|
| 需求输入 | 用户输入自然语言需求 | 能创建任务 ID |
| PRD 生成 | PM Agent 输出结构化 PRD | 包含用户故事、验收标准、边界条件 |
| 澄清问题 | 模糊需求触发追问 | 输出 3-5 个问题 |
| 人工审批 | 批准或驳回 PRD | 驳回后可带反馈重生成 |
| 任务拆解 | 将 PRD 拆成研发任务 | 每个任务有验收标准和依赖 |
| 上下文包 | 生成 `task_context.json` | 可复制给外部 Coding Agent |
| 流程回放 | 展示可审计事件 | 展示状态、产物、审批和摘要 |

## P1：60-90 天

| 功能 | 说明 |
|:---|:---|
| GitHub 结构读取 | 读取目录、语言、关键文件，不自动改代码 |
| Jira/Linear 单向创建 | 从任务拆解结果创建外部任务 |
| 执行结果回收 | 回收 PR、Commit、执行摘要 |
| QA 建议 | 生成测试场景、风险点和人工执行清单 |
