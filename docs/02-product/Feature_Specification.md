# 功能规格

> 产品范围以 [PRD](../../PRD.md) 为准，本文只保留功能清单和优先级。

## P0：30 天 POC

| 功能 | 说明 | 验收 |
|:---|:---|:---|
| 需求输入 | 用户输入一句或一段自然语言需求 | 能保存原始需求并进入分析 |
| 模糊度判断 | 判断需求是否足够清晰 | 输出清晰 / 需澄清及原因 |
| 澄清问题 | 针对信息缺口生成问题 | 输出 3-5 个分级问题 |
| 用户补充 | 用户回答澄清问题 | 回答内容进入后续生成 |
| PRD 生成 | 输出结构化 PRD | 包含目标、用户故事、范围、流程和非目标 |
| AC 生成 | 输出验收标准 | 覆盖主流程、异常流程和边界场景 |
| 自动补漏 | 检查遗漏项 | 输出边界、异常、假设和待确认项 |
| 评审输出 | 汇总评审材料 | 提供 PRD、AC、待确认项和修改记录 |

## P1：60-90 天

| 功能 | 说明 |
|:---|:---|
| 团队模板库 | 支持自定义 PRD 模板和 AC 模板 |
| 版本对比 | 比较不同版本 PRD 的变更 |
| 评审协作 | 支持评论、采纳、驳回和重新生成 |
| 需求质量评分 | 根据完整度、可测试性和边界覆盖评分 |

## P2：后续

- 行业场景模板。
- 历史需求复用。
- 需求评审看板。
- 轻量权限和团队空间。
