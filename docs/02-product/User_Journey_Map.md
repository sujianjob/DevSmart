# 用户旅程

## 核心旅程：从需求到任务上下文包

| 阶段 | 用户动作 | 系统动作 | 产物 |
|:---|:---|:---|:---|
| 输入需求 | PM 输入自然语言 | 创建任务 | 任务 ID |
| 生成 PRD | PM 等待或补充信息 | 生成 PRD / 澄清问题 | PRD 初稿 |
| 审批 | TL 批准或驳回 | 中断或继续流程 | 审批记录 |
| 拆任务 | TL 查看任务 | 自动拆解 | 任务列表 |
| 生成上下文 | 研发查看任务 | 生成上下文包 | `task_context.json` |
| 执行回收 | 人或外部 Agent 执行 | 回收摘要 | PR/Commit 摘要 |
| 复盘 | 管理者查看流程 | 展示事件线 | 审计轨迹 |

## 关键体验目标

- PM 不从空白文档开始。
- TL 不从 PRD 手工拆任务。
- 研发不靠口头追问拿背景。
- 管理者能看到流程卡点。
