# 成功指标

## 30 天 POC 指标

| 指标 | 目标 |
|:---|:---|
| PRD 生成成功率 | ≥ 80% |
| PRD 初稿可采纳率 | ≥ 50% |
| 任务拆解可采纳率 | ≥ 60% |
| 从需求到任务包耗时 | ≤ 10 分钟 |
| 内测用户愿意继续使用比例 | ≥ 60% |

## 采集方式

- PRD 审批通过率。
- PRD 驳回原因。
- 任务拆解人工修改比例。
- 用户对上下文包的评分。
- 从需求提交到上下文包生成的耗时。

## 暂不作为 POC 核心指标

- 企业 NPS。
- 付费转化。
- 全流程自动化率。
- 完整回归测试缩短比例。

这些指标需要真实用户和更完整集成后再评估。
