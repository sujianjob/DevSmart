# 成功指标

## 30 天 POC 指标

| 指标 | 目标 |
|:---|:---|
| PRD 初稿可采纳率 | ≥ 60% |
| AC 可测试性评分 | ≥ 4/5 |
| 澄清问题有效率 | ≥ 70% |
| 评审中新增重大遗漏数 | ≤ 2 个 / 需求 |
| 从需求到评审版需求包耗时 | ≤ 10 分钟 |
| 内测用户愿意继续使用比例 | ≥ 60% |

## 采集方式

- PRD 评审通过率。
- PRD 人工修改比例。
- AC 被修改或删除的比例。
- 澄清问题被用户认为“有帮助”的比例。
- 待确认项在评审中被采纳的比例。
- 从需求提交到评审版输出的耗时。

## 暂不作为 POC 核心指标

- 付费转化。
- 企业 NPS。
- 完整需求管理覆盖率。
- 跨团队协作效率。

这些指标需要真实团队长期使用后再评估。
